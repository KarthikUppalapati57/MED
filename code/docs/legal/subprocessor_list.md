# RestOps-360 Subprocessor List

**Effective date:** July 24, 2026  
**Last updated:** July 24, 2026

This page identifies subprocessors authorized to process customer personal data for the production RestOps-360 platform.

| Subprocessor | Service category | Purpose |
|---|---|---|
| Supabase | Cloud database and authentication | Authentication, database, storage, and backend functions |
| Vercel | Application hosting | Web application hosting, deployment, and content delivery |
| Microsoft Azure, including Azure OpenAI and Azure Communication Services | Cloud, AI, and communications | AI-assisted processing, cloud services, and user-requested SMS delivery |
| Stripe | Payments | Subscription billing, ACH debit, payment processing, and connected-account services |
| Resend | Email delivery | Transactional email delivery |

## Updates

We will update this list before a new material subprocessor begins processing customer personal data and provide notice as described in the Data Processing Addendum.

Technologies under evaluation, in development, or planned for future use are not production subprocessors until enabled and added to this list.

Questions or objections based on reasonable data-protection grounds may be sent to `contact@mindfultechsol.com` with the subject **Subprocessor Question**.
