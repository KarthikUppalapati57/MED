# AI Usage Policy

Status: Drafted for product/legal review.

## Approved Production Provider

Azure OpenAI is the approved production AI provider. The exact Azure deployment name and model label must be verified before public publication.

## Active AI Features

- Invoice extraction and normalization.
- AI Assistant / AI Insights Copilot.
- Optional chatbot if enabled.

## Human Review Requirement

AI-extracted invoice information must be reviewed and approved by an authorized human before becoming an operational record.

## Training Policy

Customer information is not used to train public or shared AI models.

## Data Sent to AI Provider

Data sent may include invoice text/extraction data, structured invoice context, operational context selected by the tenant scope, and user prompts for assistant/chatbot features.

## Feature Classification Decision

| Feature | Classification | Decision Needed |
| --- | --- | --- |
| Invoice extraction | To Be Finalized | Production or assisted/beta |
| AI Assistant / AI Insights Copilot | To Be Finalized | Production or beta/experimental |
| Optional chatbot | To Be Finalized | Production or beta/experimental |

If classified as beta/experimental, publish limitations, availability, accuracy, and support disclaimers.

## Accuracy Limitations

AI output may be incomplete or inaccurate. Users are responsible for reviewing AI output before using it for financial, tax, payment, or operational decisions.
