# Subprocessor Management

Status: Recommended after launch, but provider region confirmation is mandatory before production.

## Public Subprocessor Fields

- Provider name.
- Service purpose.
- Data categories processed.
- Status: active, planned, deprecated, removed.
- Primary region/country.
- Data residency notes.
- Effective date.
- Last reviewed date.

## Current Active Providers

- Supabase.
- Vercel.
- Azure OpenAI.
- Stripe ACH Debit.
- Stripe Connect Custom.
- Resend.

## Planned/Future Providers

- Checkbook.
- Dwolla.
- Plaid.
- Google Cloud Run.

## Removed/Disabled Providers

- Google Gemini.
- PostHog.
- Sentry.
- EmailJS.
- Upstash Redis.

## Change Process

Adding a production subprocessor requires security/legal review, region documentation, privacy/DPA updates, and customer notice if required by contract.
